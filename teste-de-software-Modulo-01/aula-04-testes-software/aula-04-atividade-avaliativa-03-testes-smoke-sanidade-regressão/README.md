### Atividade Avaliativa
---
### Cenário: Uma nova versão de um sistema bancário foi implantada com correção no login e um ajuste na exibição do saldo tela inicial.
### Propor:  
01. 05 cenários para cada um dos tipos testes vistos (Smoke, Sanidade e Regressão)

## TESTE DE SMOKE
### ID: TESTE01 (SMOKE)

- **TITULO:** CONFIRMAÇÃO DE LOGIN VÁLIDO DE USUÁRIO

- **PRE-CONDIÇÕES:** ACESSO VÁLIDO NA TELA DE LOGIN  

- **PASSOS DO TESTE:** 
01. **PASSO01:** USUÁRIO COM ACESSO A TELA DE LOGIN
02. **PASSO02:** INFORMAR ID DE USUÁRIO E SENHA VÁLIDA
03. **PASSO03:** CLICAR EM ENTRAR  

- **RESULTADO ESPERADO:** SISTEMA VALIDÁ OS DADOS DO USUÁRIO SEM FALHAS E REDIRECIONADO PARA TELA INCIAL  

- **JUSTIFICATIVA:** ESTE TESTE VERIFICA SE O SISTEMA ESTA VALIDANDO DADOS VÁLIDOS DE USUÁRIO APÓS CORREÇÃO IMPLEMENTADA.  

### ID: TESTE02 (SMOKE)

- **TITULO:** BLOQUEIO DO ACESSO POR DADOS INVÁLIDOS

- **PRE-CONDIÇÕES:** ACESSO NA TELA DE LOGIN

- **PASSOS DO TESTE:** 
01. **PASSO01:** USUÁRIO COM ACESSO A TELA DE LOGIN
02. **PASSO02:** INFORMAR ID DE USUÁRIO VÁLIDO E SENHA INVÁLIDA
03. **PASSO03:** CLICAR EM ENTRAR  

- **RESULTADO ESPERADO:** SISTEMA NÃO PERMITE ACESSO A TELA INICIAL EXIBE MENSAGEM DE ERRO NOS DADOS DO USUÁRIO SEM ERROS E SEM EXPOR DADOS DO USUÁRIO

- **JUSTIFICATIVA:** ESTE TESTE VERIFICA SE O SISTEMA ESTÁ RECONHECENDO DADOS INVALIDOS NA TELA DE LOGIN APÓS A CORREÇÃO IMPLEMENTADA.

### ID: TESTE03 (SMOKE)

- **TITULO:** EXIBIÇÃO CORRETA DE VALOR DO SALDO POSITIVO

- **PRE-CONDIÇÕES:** ACESSO VÁLIDO NA TELA INICIAL COM SALDO POSITIVO DISPONIVEL

- **PASSOS DO TESTE:** 
01. **PASSO01:** LOGIN COM USUÁRIO VÁLIDO A TELA INICIAL
02. **PASSO02:** VIZUALIZAR SALDO POSITIVO NA TELA INICIAL

- **RESULTADO ESPERADO:** SISTEMA APRESENTA SALDO POSITIVO NA TELA INICIAL

- **JUSTIFICATIVA:** ESTE TESTE CONFIRMA QUE O SALDO SERA APRESENTADO NA TELA INICIAL APÓS VALIDAÇÃO DE DADOS DE USUÁRIO VALIDOS COM SUCESSO APOS AJUSTE IMPLEMENTADO.

### ID: TESTE04 (SMOKE)

- **TITULO:** SALDO OCULTO NA TELA INICIAL  

- **PRE-CONDIÇÕES:** ACESSO VÁLIDO NA TELA INICIAL    

- **PASSOS DO TESTE:** 
01. **PASSO01:** LOGIN COM USUÁRIO VÁLIDO A TELA INICIAL
02. **PASSO02:** VIZUALIZAR SALDO NA TELA INICIAL
03. **PASSO03:** CLICAR EM ICONE PARA OCULTAR SALDO NA TELA INICIAL  

- **RESULTADO ESPERADO:** SISTEMA OCULTA O SALDO NA TELA INICIAL COM ASTERISTICOS

- **JUSTIFICATIVA:** ESTE TESTE VERIFICA SE A USABILIDADE QUE PERMITE OCULTAR O SALDO DA CONTA ESTA FUNCIONANDO APÓS AJUSTE IMPLEMENTADO.  

### ID: TESTE05 (SMOKE)

- **TITULO:** CARREGAMENTO DA TELA INICIAL SEM ERROS DE FUNCIONALIDADES

- **PRE-CONDIÇÕES:** ACESSO VÁLIDO NA TELA INICIAL

- **PASSOS DO TESTE:** 
01. **PASSO01:** USUÁRIO COM ACESSO VÁLIDO A TELA INICIAL
02. **PASSO02:** CLICAR EM ALGUMA FUNCIONALIDADE DISPONIVEL NA TELA INICIAL (EX: EXTRATO OU SAIR)

- **RESULTADO ESPERADO:** SISTEMA EXIBE AS FUNCIONALIDADES DA TELA INICIAL  

- **JUSTIFICATIVA:** ESTE TESTE VERIFICA SE O SISTEMA EXIBE TODAS AS FUNCIONALIDADES DA TELA INICIAL SEM ERROS APÓS AJUSTE IMPLEMENTADO.

## TESTE DE SANIDADE

### ID: TESTE01 (SANIDADE)

- **TITULO:** LOGIN COM DADOS VÁLIDOS

- **PRE-CONDIÇÕES:** ACESSO VÁLIDO NA TELA DE LOGIN  

- **PASSOS DO TESTE:**

02. **PASSO02:** CLICAR EM ENTRAR  

- **RESULTADO ESPERADO:** USUÁRIO TEM ACESSO VÁLIDO É DIRECIONADO A TELA INICIAL

- **JUSTIFICATIVA:** ESTE TESTE CONFIRMA QUE A FUNICONALIDADE DE LOGIN ESTA FUNCIONADO SEM ERROS APÓS A CORREÇAO IMPLEMENTADA

- 
- **JUSTIFICATIVA:** ESTE TESTE VERIFICA SE O SISTEMA IDENTIFICA COM SEGURANÇA ACESSOS INVALIDOS A TELA DE LOGIN APÓS A CORREÇÃO IMPLEMENTADA.

- **TITULO:** LOGIN COM DADOS BIOMÉTRICOS

### ID: TESTE04 (SANIDADE)

- **TITULO:** ATUALIZAÇÃO DO SALDO APOS TRASNFERÊNCIA DE VALOR

- **PRE-CONDIÇÕES:** ACESSO VÁLIDO NA TELA INICIAL DURANTE TRANSFERÊNCIA DE VALOR

- **PASSOS DO TESTE:**

02. **PASSO02:** VIZUALIZAR SALDO TELA INICIAL
03. **PASSO03:** REALIZAR TRASNFERÊNCIA DE VALOR
04. **PASSO04:** VIZUALIZAR SALDO TELA INICIAL

- **RESULTADO ESPERADO:** SISTEMA APRESENTA SALDO ATUALIZADO NA TELA INICIAL APOS TRANSFERÊNCIA

- **JUSTIFICATIVA:** ESTE TESTE CONFIRMA QUE O AJUSTE REALIZADO NÃO AFETOU O SERVIÇO DE ATUALIZAÇÃO APÓS UMA TRASNFERÊNCIA DE VALOR DO SALDO DO USUÁRIO

## TESTE DE REGRESSÃO  

### ID: TESTE01 (REGRESSÃO)

- **TITULO:** INATIVIDADE NA TELA INICIAL

- **PRE-CONDIÇÕES:** ACESSO A TELA INICIAL INATIVO POR MAIS DE 5 MINUTOS

- **PASSOS DO TESTE:** 
01. **PASSO01:** ACESSO VÁLIDO A TELA INICIAL
02. **PASSO02:** ACESSO COM INATIVIDADE NA TELA INICIAL
03. **PASSO02:** ACESSO ENCERRADO A TELA INICIAL

- **RESULTADO ESPERADO:** USUÁRIO E DIRECIONADO PARA A TELA DE LOGIN APOS FICAR INATIVO POR MAIS DE 5 MINUTOS NA APLICAÇÃO

- **JUSTIFICATIVA:** VERIFICA SE O SISTEMA REALIZA O ENCERRAMENTO DA SESSÃO APOS USUA´RIO FICAR INATIVO PELO PERIODO DETERMINADO APÓS AJUSTE IMPLEMENTADO

### ID: TESTE02 (REGRESSÃO)

- **TITULO:** REDEFINIÇÃO DE SENHA  

- **PRE-CONDIÇÕES:** ACESSO NA TELA DE LOGIN  

- **PASSOS DO TESTE:** 
01. **PASSO01:** ACESSO A TELA DE LOGIN
02. **PASSO02:** CLICAR EM ESQUECI MINHA SENHA

- **RESULTADO ESPERADO:** USUÁRIO RECEBE E-MAIL COM CODIGO PARA REDEFINIR SENHA E FAZ LOGIN COM NOVA SENHA
- 
- **JUSTIFICATIVA:** ESTE TESTE CONFIRMA O FLUXO DE REDEFINIÇÃO DE SENHA NA TELA DE LOGIN APÓS CORREÇÃO IMPLEMENTADA.
- 
### ID: TESTE03 (REGRESSÃO)

- **TITULO:** TELA BLOQUEADA POR ERRO DE USUÁRIO E SENHA

- **PRE-CONDIÇÕES:** ACESSO A TELA DE LOGIN COM DADOS INVÁLIDOS

- **PASSOS DO TESTE:** 
01. **PASSO01:** ACESSO A TELA DE LOGIN
02. **PASSO02:** INSERIR DADOS IVÁLIDOS NO CAMPO DE LOGIN E SENHA ACIMA DE 3 TENTATIVAS
03. **PASSO03:** CLICAR EM ENTRAR

- **RESULTADO ESPERADO:** BLOQUEIO TEMPORARIO DO SISTEMA

- **JUSTIFICATIVA:** GARANTIR QUE O SISTEMA ESTÁ REALIZANDO O BLOQUEIO SEM EXIBIR DADOS PRIVADOS DO USUÁRIO

### ID: TESTE04 (REGRESSÃO)

- **TITULO:** TENTATIVAS DE LOGIN COM DADOS EM BRANCO

- **PRE-CONDIÇÕES:** ACESSO A TELA DE LOGIN

- **PASSOS DO TESTE:** 
01. **PASSO01:** TELA DE LOGIN EM BRANCO
02. **PASSO02:** CLICAR EM ENTRAR

- **RESULTADO ESPERADO:** SISTEMA SOLICITA DADOS DE LOGIN E SENHA

- **JUSTIFICATIVA:** CONFIRMAR QUE O SISTEMA IDENTIFICA QUE DADOS NAO FORAM INSERIDOS INVALIDANDO ACESSOS SEM DADOS DE LOGIN E SENHA APÓS A CORREÇÃO.

### ID: TESTE05 (REGRESÃO)

- **TITULO:** EXIBIÇÃO DE TELA INICIAL EM MODO ESCURO E MODO CLARO

- **PRE-CONDIÇÕES:** APLICATIVO OU DISPOSITIVO COM FUNÇÃO MODO ESCURO/MODO CLARO APLICADA

- **PASSOS DO TESTE:** 
01. **PASSO01:** HABILITAR MODO ESCCURO NO DISPOSITIVO
02. **PASSO02:** REALIZAR LOGIN VALIDO
03. **PASSO03:** VIZUALIZAR TELA INICIAL
04. **PASSO04:** HABILITAR MODO CLARO NO DISPOSITIVO
05. **PASSO05:** VIZUALIZAR TELA INICIAL

- **RESULTADO ESPERADO:** TELA INICIAL EXIBE FUCIONALIDADES COM VIZIBILIDADE ADAPTADA AO MODO ESCOLHIDO PELO USUARIO

- **JUSTIFICATIVA:** ESSE TESTE GARANTI QUE AS FUNCIONALIDADES DA TELA INICIAL NÃO SOFRERAM ERROS DE VIZUALIZAÇÃO PARA TEMA ESCURO DA APLICAÇÃO APÓS AJUSTE DA TELA INICIAL.
