### Atividade Avaliativa
---
### Cenário: Uma nova versão de um sistema bancário foi implantada com correção no login e um ajuste na exibição do saldo tela inicial.
### Propor:  
01. 05 cenários para cada um dos tipos testes vistos (Smoke, Sanidade e Regressão)
02. Justificar a escolha de cada
03. Apresentar testes para a turma

- **CENÁRIO 01:**
- ## ID: TESTE01 (SMOKE)

- **TITULO:** CORREÇÃO DE LOGIN E EXIBIÇÃO DE SALDO NA TELA INICIAL

- **PRE-CONDIÇÕES:** ACESSO VÁLIDO A TELA DE LOGIN E TELA INICIAL 

- **PASSOS DO TESTE:** 
01. **PASSO01:** USUÁRIO COM ACESSO A TELA DE LOGIN
02. **PASSO02:** INFORMAR SENHA VÁLIDA
03. **PASSO03:** CLICAR EM ENTRAR  

- **RESULTADO ESPERADO:** USUÁRIO VÁLIDO E REDIRECIONADO PARA TELA INCIAL

- **JUSTIFICATIVA:** ESTE TESTE VERIFICA SE O SISTEMA ESTA VÁLIDO E CARREGANDO CORRETAMENTE ENTRE A TELA INICIAL E A TELA DE LOGIN

- ## ID: TESTE01 (SANIDADE)

- **TITULO:** VALIDAR CORREÇÃO DE LOGIN E EXIBIÇÃO DO SALDO NA TELA INICIAL

- **PRE-CONDIÇÕES:** ACESSO A TELA DE LOGIN COM DADOS VÁLIDOS

- **PASSOS DO TESTE:** 
01. **PASSO01:** REALIZAR ACESSO A TELA EM CONTA QUE APRESENTOU O ERRO COM DADOS VÁLIDOS
02. **PASSO02:** VIZUALILIZAR TELA DE LOGIN

- **RESULTADO ESPERADO:** O SISTEMA DEVE REALIZAR O LOGIN SEM ERROS E APRESENTAR O SALDO DISPONIVEL ATUALIZADO

- **JUSTIFICATIVA:** ESSE TESTE VERIFICA PONTUALMENTE UMA CORREÇÃO REALIZADA ANTERIOR NA TELA DE LOGIN E NA TELA INICIAL

- ## ID: TESTE01 (REGRESSÃO)

- **TITULO:** GARANTIA DE FUNCIONALIDADES APÓS CORREÇÃO DE LOGIN E EXIBIÇÃO DE SALDO NA TELA INICIAL

- **PRE-CONDIÇÕES:** ACESSO VÁLIDO A TELA DE LOGIN E TELA INICIAL 

- **PASSOS DO TESTE:** 
01. **PASSO01:** ABRIR SISTEMA NA TELA DE LOGIN COM DADOS VALIDOS
02. **PASSO02:** ACESSO VALIDADO A TELA INICIAL
03. **PASSO03:** REALIZAR CONSULTA DO SALDO
04. **PASSO04:** SAIR DO SISTEMA

- **RESULTADO ESPERADO:** O ACESSO AO SISTEMA OCORRE CORRETAMENTE COM OS DADOS VALIDOS ABRINDO A TELA INICIAL, EXIBI O SALDO ATUALIZADO DE MANEIRA CORRETA E ENCERRA O ACESSO DA TELA INICIAL APÓS CLICAR NO ÍCONE DE SAIR
