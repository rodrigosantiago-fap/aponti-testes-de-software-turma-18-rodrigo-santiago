- **CENÁRIO 01:**
- ## ID: TESTE01 (SMOKE)

- **TITULO:** CORREÇÃO DE LOGIN E EXIBIÇÃO DE SALDO NA TELA INICIAL

- **PRE-CONDIÇÕES:** ACESSO VÁLIDO A TELA DE LOGIN E TELA INICIAL 

- **PASSOS DO TESTE:** 
01. **PASSO01:** USUÁRIO COM ACESSO A TELA DE LOGIN
02. **PASSO02:** INFORMAR SENHA VÁLIDA
03. **PASSO03:** CLICAR EM ENTRAR  

- **RESULTADO ESPERADO:** USUÁRIO VÁLIDO E REDIRECIONADO PARA TELA INCIAL

- **JUSTIFICATIVA:** ESTE TESTE VERIFICA SE O SISTEMA ESTA VÁLIDO E CARREGANDO CORRETAMENTE ENTRE A TELA INICIAL E A TELA DE LOGIN

- ## ID: TESTE01 (SANIDADE)

- **TITULO:** VALIDAR CORREÇÃO DE LOGIN E EXIBIÇÃO DO SALDO NA TELA INICIAL

- **PRE-CONDIÇÕES:** ACESSO A TELA DE LOGIN COM DADOS VÁLIDOS

- **PASSOS DO TESTE:** 
01. **PASSO01:** REALIZAR ACESSO A TELA EM CONTA QUE APRESENTOU O ERRO COM DADOS VÁLIDOS
02. **PASSO02:** VIZUALILIZAR TELA DE LOGIN

- **RESULTADO ESPERADO:** O SISTEMA DEVE REALIZAR O LOGIN SEM ERROS E APRESENTAR O SALDO DISPONIVEL ATUALIZADO

- **JUSTIFICATIVA:** ESSE TESTE VERIFICA PONTUALMENTE UMA CORREÇÃO ANTERIOR NA TELA DE LOGIN E NA TELA INICIAL
