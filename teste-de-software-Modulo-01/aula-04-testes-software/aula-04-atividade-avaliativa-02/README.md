**ETAPA 1** - Compreensão do Cenário um sistema bancário permite que usuários realizem login, acessem sua conta e visualizem seu saldo atual.  
---
**Tarefa:**
- **IDENTIFICAR:**

1. **FUNCIONALIDADES ENVOLVIDAS:**
- LOGIN COM CREDENCIAIS VÁLIDAS
- LOGIN COM CREDENCIAIS DE USUÁRIO E SENHA INVÁLIDAS COM CADASTRO BIMÉTRICO VÁLIDO

2. **FLUXO PRINCIPAL:**
- F01 - LOGIN: USUÁRIO E SENHA CORRETOS
- F02 - USUÁRIO E SENHA VALIDOS
- F03 - USUÁRIO É DIRECIONADO PARA TELA INICIAL
- F04 - USUÁRIO TEM ACESSO A TELA INICIAL E VIZUALIZA SALDO

3. **VARIAÇÕES DE FLUXO:**

- F01 - LOGIN: USUÁRIO E SENHA INCORRETAS
- F02 - USUÁRIO E SENHA IVALIDOS
- F02 - SISTEMA DISPONIBILIZA LOGIN BIOMETRICO
- F03 - USUARIO COM BIOMETRIA CADASTRADA
- F04 - BIOMETRIA VALIDA
- F05 - USUÁRIO DIRECIONADO PARA TELA INICIAL
- F06 - USUÁRIO TEM ACESSO A TELA INICIAL E VIZUALIZA SALDO
