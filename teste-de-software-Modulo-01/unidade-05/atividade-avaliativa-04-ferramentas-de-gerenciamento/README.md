# Atividade Avaliativa:

- Compreender como casos de teste estruturados podem ser organizados, rastreados e gerenciados dentro de uma ferramenta de gestão utilizada no mercado.
- Durante o projeto, os casos de teste foram inicialmente criados em formato textual (documento, planilha ou template). Agora, será necessário migrar esses casos para uma ferramenta de gerenciamento, garantindo organização, rastreabilidade e fácil acompanhamento da execução.
OBS: Esta ferramenta poderá ser diferente de acordo com a empresa dos residentes.

# Atividade Avaliativa:
- Cadastro de Casos de Teste
- Os casos a serem migrados devem conter todas às informações obrigatórias e necessárias em cada sistema.
ID (Geralmente é automático)
Titulo
Pré-condições
Passos
Resultado esperado

# Atividade Avaliativa:
- Montagem de Ciclo de Testes
- Agrupar nas ferramentas os casos de teste de acordo com tipos de ciclo (conjuntos) de teste.
- Smoke
- Sanity
- Regression

# Atividade Avaliativa:
- Entregável
- Print de todos casos de teste registrados na ferramenta de gerenciamento do projeto
- Estrutura clara e padronizada
- Pelo menos 1 caso com execução simulada
