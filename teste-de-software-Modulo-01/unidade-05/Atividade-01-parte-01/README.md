# ATIVIDADE AVALIATIVA ESTRATÉGIA DE TESTES  
- Pensar como responsável pela qualidade de um sistema, tomando decisões estratégicas de teste com base em contexto, riscos e limitações reais.  
- Considere o cenário atual do projeto em que estão participando e analisem às seguintes características:

1. Possui múltiplas funcionalidades principais
2. Será utilizado por usuários reais
3. Está em fase de desenvolvimento ativo
4. Possui prazo de entrega definido
5. Conta com um time reduzido
6. Sofrerá evoluções e correções ao longo do projeto
